
1.Reflect on the differences between static and interactive visualizations.

Static visualizations, such as thosse we create using Matplotlib, are useful for presenting fixed insights and
summaries. They are simple, fast to render, and ideal for reports or documentation.

Interactive visualizations provide a more dynamic experience and allow users to interact with the data or
explore additional dimensions.

2.Write a short paragraph discussing the advantages of using dashboards for real-time data exploration.

Dashboards such as Dash or streamlit allow users to filter, zoom, and drill down into data in real time, 
making them especially useful for monitoring business performance and identifying trends quickly.

3.Explain how interactive tools like Plotly can improve data communication in professional settings.

Tools like Plotly improve data communication by enabling interactivity, tooltips, and visual clarity. 
This helps users better understand complex datasets and supports data-driven decision-making in 
professional environments.
